# Nuke parity worklist

Generated by `python tools/parity_review_book.py --worklist` from the review book's marks: every default, label, widget type, order, missing knob, failing or missing behaviour case and failing widget behaviour, one row each, sorted by the node's rank weight (the audit's 1 / rank; a main-tab knob counts twice). The full list with values is `worklist.json` beside this file. A default difference the pairing accepts on purpose (`skip_default`) is listed as accepted with its reason and is not work. Knobs the audit does not count (rows without a scripting name, Python callbacks, file-format and GPU options) keep their marks on the node pages and are not listed here.

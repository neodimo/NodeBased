# Fire shot

Run `make_shot.py` to regenerate the editable NodeBased graph. `render_evidence.py`
bakes the small fuel source to frame 24, renders frames 8, 16 and 24, and writes
a frame-16 comparison with fire lighting on meshes switched off. The shot contains
a floor, a stone beside the fire and one dim blue fill light. Its simulation cache
is disposable; only the graph, scripts and rendered stills are deliverables.

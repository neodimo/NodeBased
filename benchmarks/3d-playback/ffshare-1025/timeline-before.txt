Causes (a debug print of which parts of the cache key differed, one run of the furnished room):
  shadow_ready  the shadow triangles and their BVH are packed again: the key holds each geometry's vertex and triangle arrays by identity (they are read-only), and the full-size scene is a different set of array objects with the same content
  resident_built  the resident scene (vertices, materials, textures, light tables) is built again for the same reason (vertices, triangles, uvs by identity; then the shadow data's identity, which the first miss changed)
  staging_ready  the readback buffer for the full size is allocated again (the half-size frames' buffer is smaller; the stop's full-quality picture of a splat scene released the big one)

# Naming notebook

- **Carta** — architecture codename; temporary, collision-prone.
- **Score** — durable edit graph.
- **Contract** — capabilities and lowering layer.
- **Plan** — legalized executable description.
- **Chart** — representation-specific adapter.
- **Footprint** — sampling query with local measure.
- **Intent / Op / Resource** — retain their direct meanings.

Names describe roles, not Python classes or current backends. Do not establish a
public brand until experiments stabilize the concepts.
